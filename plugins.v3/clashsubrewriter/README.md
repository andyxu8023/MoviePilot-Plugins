# Clash 订阅改写（ClashSubRewriter）

定时拉取机场订阅，按可编辑的 YAML 规则改写 Clash 配置，校验通过后备份并原子替换到指定目录，可选在写盘后自动重启容器。

适用前提：**订阅地址直接返回 Clash YAML**（例如 iKuuu 的 `?clash=3` 链接）。插件不做订阅转换，也不管理节点。

## 它解决什么

机场订阅下载下来通常还要手改一轮：换监听端口、开启 `allow-lan`、加一个自动切换组、把面板密钥填进去……本插件把这套手工动作固化成声明式规则，每次更新自动执行，改动之外的字节保持原样，diff 干净可审。

## 改写规则

配置表单最下方的 YAML 文本框即是规则，支持的字段：

| 字段 | 作用 |
| --- | --- |
| `set` | 覆盖或新增顶层**标量**键（`port`、`allow-lan`、`secret` …） |
| `insert_after` | 新增键的插入锚点（锚点不存在时退回顶部块首行，不会失败） |
| `delete` | 删除顶层键（整块删除；键名写错会直接报错，避免静默忽略） |
| `delete_if_present` | 删除「存在才删」的顶层键，用于清掉机场按 UA 追加的提示块 |
| `groups` | 新增策略组，YAML 片段原文照抄插入，缩进自动对齐既有组 |
| `references` | 往既有策略组的 `proxies` 里插入引用（`position: first|last`，已存在则跳过） |
| `rules_prepend` / `rules_append` | 在 `rules` 头部/尾部加规则 |

两个占位符：

- `@MEMBERS(正则)` —— 只在 `groups` 片段里生效。按正则匹配订阅自身的节点名（不区分大小写），把这一行展开成命中的全部成员。例如 `@MEMBERS(🇭🇰)` 自动收集所有香港节点，`@MEMBERS(🇭🇰.*IEPL)` 只收香港的 IEPL 线路。机场新增或改名节点后无需改规则；**一个都没匹配到时报错并放弃本次写入**，不会写出空组。
- `@SECRET` —— 在 `set` 里引用配置项「面板密钥」，规则文本与详情页都不落明文（展示时自动打码）。留空则报错而不是写空值。

## 安全落盘

顺序是：拉取 → 改写 → **校验** → 备份 → 原子替换（同目录临时文件 + fsync + `os.replace`）。

校验包含：YAML 可解析、`set` 已生效、`delete` 已移除、节点与规则数量未变、策略组无重名、组内成员与规则目标都存在。任何一步不通过都**不会触碰目标文件**，失败原因写进详情页并（可选）推送通知。

备份默认落在插件数据目录（`<配置文件名>.mpbak-时间戳`），按数量轮转，不污染目标目录。

## 容器重启

`dreamacro/clash` 这类核心不会热加载配置文件，所以默认开启「写盘成功后自动重启容器」。实现走 Docker 的 Unix socket（`/var/run/docker.sock`）直调 API，不依赖 `docker` 命令，也不受 MoviePilot 出口代理影响（代理往往就架在同一个 Clash 上）。只重启配置里指定的那一个容器；容器名写错或 socket 不存在时只提示重启失败，**不会把已完成的配置更新判为失败**。跳过写盘时不重启。

## 操作入口

- 命令 `/clashsub`：立即执行一次更新。
- 详情页按钮：立即更新（写盘）、预览差异（不写盘）、只重启容器。
- 定时：五段 Cron，按 MoviePilot 调度器时区；注意星期字段 `0=周一`（与 Linux crontab 不同）。

## 已知站点差异（iKuuu）

- `python-requests` 默认 UA 会被拦成 **HTTP 403**，需使用 Clash 客户端或浏览器 UA（默认已设为 `mihomo/1.18.1`）。
- ClashForWindows / ClashX 一类 UA 虽返回 200，但订阅里会额外塞大写顶层键 `Proxy` / `Proxy Group` / `Rules`（内容是「客户端版本过旧」的假节点）。规则里的 `delete_if_present` 负责清掉。
- 订阅每次抓取的节点 `server` 域名都会轮换，因此「内容一致时跳过写盘」对该站基本无效，每轮都会真实替换文件。

## 依赖

无第三方新增依赖，使用宿主已有的 `requests`、`PyYAML`、`apscheduler`。
